# Glosario del Proyecto - Cuotin

## Términos del Negocio (Finanzas & Tarjetas de Crédito)
- **Cuotin**: Nombre de la marca y plataforma web para el cálculo y control de gastos en cuotas con tarjeta de crédito en Argentina.
- **Cuota Mensual**: Importe exacto resultante de dividir el Monto Total de una compra entre la Cantidad de Cuotas seleccionadas.
- **Mes de Inicio / Entrada**: Mes del calendario a partir del cual impacta la primera cuota en el resumen de la tarjeta.
- **Resumen Mensual**: Pantalla o informe que consolida el total acumulado a pagar en un mes determinado.
- **¿Me Alcanza? / Diagnóstico**: Indicador visual que evalúa si la suma de las cuotas del mes es saludable o requiere atención.
- **Categoría**: Clasificación temática del gasto (Indumentaria, Tecnología, Supermercado, Hogar, Viajes, Varios).

## Componentes de Interfaz y Términos Técnicos
- **SPA (Single Page Application)**: Aplicación de una sola página HTML donde el contenido cambia dinámicamente mediante JS sin recargas.
- **Bottom Navigation Bar**: Barra de navegación fija en el borde inferior para celulares.
- **Modal Emergente (Popup)**: Ventana superpuesta que muestra detalles ampliados (desglose o más info) sin abandonar la pantalla actual.
- **Toast Notification**: Alerta visual flotante de confirmación (verde de éxito) que aparece tras guardar una compra.
- **Empty State**: Componente de diseño que informa amigablemente cuando un mes no posee cuotas activas a pagar.
- **Skeleton Loading**: Indicador de carga animado con bloques grises mientras se procesa la información.
- **localStorage**: Almacenamiento local persistente dentro del navegador del usuario.
